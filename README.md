## เกี่ยวกับคอร์สนี้ (About This Course)

คอร์สนี้ถูกออกแบบมาเพื่อสอน Three.js อย่างครบถ้วนตั้งแต่พื้นฐานไปจนถึงระดับผู้เชี่ยวชาญ  
ทุก Part จะมีคำอธิบายเป็นภาษาไทย พร้อม code examples ที่สมบูรณ์และใช้งานได้จริง

## สิ่งที่ต้องรู้ก่อนเรียน (Prerequisites)

- HTML, CSS, JavaScript พื้นฐาน
- ES6+ (Arrow functions, modules, async/await)
- Node.js & npm เบื้องต้น
- ไม่จำเป็นต้องรู้ 3D มาก่อน

## เครื่องมือที่ใช้ (Tools Required)

- **Node.js** 18+ 
- **VS Code** หรือ editor ที่ชื่นชอบ
- **Browser** ที่รองรับ WebGL2 (Chrome/Firefox/Edge)
- **Blender** (optional, สำหรับ Module 4+)

## วิธีใช้คอร์สนี้ (How to Use)

1. อ่านตามลำดับจาก Part 001 
2. ทำ exercise ท้ายทุก Part
3. ดู code examples และลองรันด้วยตัวเอง
4. สร้าง project ของตัวเองระหว่างเรียน
